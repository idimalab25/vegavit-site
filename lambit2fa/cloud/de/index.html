So richten Sie Ihre lambit2FA-Cloud ein

Die Cloud trägt Codes zwischen Ihren Geräten: Code am Telefon anlegen — er erscheint von selbst am Computer. Einmal einrichten, in ein paar Minuten.

Was die Cloud ist

Ein Briefkasten zwischen Ihren Geräten auf unserem Server. Ein Gerät legt einen neuen Code hinein, ein anderes holt ihn ab. Der Briefkasten weiß nicht, wem er gehört, und kann nicht lesen, was drin ist: Codes werden auf Ihrem Gerät mit einem Schlüssel versiegelt, der nie an den Server geht.

Kein Konto, keine E-Mail, kein Passwort nötig. Die Cloud kann aus bleiben — die App funktioniert ohne sie vollständig.

Schritt 1. Cloud am ersten Gerät einschalten

Öffnen Sie „Einstellungen“ und schalten Sie den Schalter „Cloud“ ein — der Cloud-Bildschirm öffnet sich. Tippen Sie auf „Cloud anlegen“. Die App zeigt ein QR-Quadrat, eine sechsstellige Zahl und eine Zeichenfolge aus 32 Zeichen — das ist der Schlüssel Ihrer Cloud. Jeder hat seine eigene Cloud.

Liegen auf dem Gerät schon Codes, fragt die App, ob alle in die Cloud sollen oder ob Sie zuerst auswählen, welche nur hier bleiben. Dazu unten „Codes, die nicht in die Cloud gehen“.

Schritt 2. Zweites Gerät verbinden

Schalten Sie am zweiten Gerät in den Einstellungen „Cloud“ ein, tippen Sie auf „Quadrat scannen“ und richten Sie die Kamera auf das Quadrat des ersten. Das zweite Gerät fragt nach sechs Ziffern — die Zahl ist in dem Moment am ersten Gerät unter dem Quadrat zu sehen (sie wechselt alle 30 Sekunden). Eingeben, auf „Bestätigen“ tippen — und die Codes kommen an.

Ab dann läuft alles von selbst: neuer Code, Änderung und Löschung erreichen Ihre anderen Geräte ohne einen einzigen Handgriff. Nichts zu merken oder aufzuschreiben: Quadrat und Zahl lassen sich jederzeit wieder anzeigen — „Einstellungen“ → „Meine Cloud verwalten“ → „Quadrat und Zahl zeigen“.

Wenn es keine Kamera gibt

Am Desktop-Computer gibt es statt der Kamera das Feld „Cloud-Schlüssel“: die 32 Zeichen von Hand eingeben (sie werden in Vierergruppen angezeigt) und auf „Cloud beitreten“ tippen. Danach dieselben sechs Ziffern. Das geschieht einmal.

Codes, die nicht in die Cloud gehen

Jeder Code kann auf nur einem Gerät bleiben — zum Beispiel Arbeitscodes nicht an den Heimcomputer senden. Code gedrückt halten → „Nicht in die Cloud senden“. So ein Code bekommt in der Liste ein durchgestrichenes Wolkensymbol.

Beim Anlegen eines neuen Codes wird die Frage „In die Cloud senden“ immer gestellt; Standard ist Senden. War ein Code schon in der Cloud und Sie nehmen ihn heraus, fragt die App, ob er von Ihren anderen Geräten gelöscht oder dort belassen werden soll.

Codes außerhalb der Cloud schützt nur eine Sicherungsdatei: Auf Ihren anderen Geräten gibt es sie nicht.

Trotzdem eine Sicherung machen

Die Cloud ist kein Speicher. Solange mindestens ein Gerät mit den Codes heil ist, bringt die Cloud sie auf ein neues. Ist keines mehr da, ist auch der Cloud-Schlüssel weg, und die Codes lassen sich nur aus einer Sicherungsdatei wiederherstellen („Sicherungen“ → „Sicherungskopie erstellen“).

Die Cloud verlassen

Auf dem Bildschirm „Cloud“ gibt es „Cloud verlassen“: Das Gerät vergisst den Schlüssel, die Codes darauf bleiben heil. Von selbst tritt es nicht wieder bei — zeigen Sie ihm den Schlüssel von einem anderen Gerät noch einmal. Der Schalter „Cloud“ in den Einstellungen ist etwas anderes: Er pausiert nur den Austausch.

Den Cloud-Schlüssel schützen

Wer den Schlüssel hat, hat Zugang zum Briefkasten. Zeigen Sie ihn Fremden nicht und fotografieren Sie den Bildschirm damit nicht: Der Schnappschuss landet in der Galerie, die andere Apps lesen. Den Schlüssel muss man nirgends aufbewahren — er ist auf Ihren Geräten.
