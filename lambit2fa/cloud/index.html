How to set up your lambit2FA cloud

The cloud carries codes between your devices: add a code on the phone and it appears on the computer by itself. Set up once, in a couple of minutes.

What the cloud is

It is a mailbox between your devices on our server. One device puts a new code in, another takes it out. The mailbox does not know whose it is and cannot read what is inside: codes are sealed on your device with a key that never goes to the server.

No account, email or password is needed. You can leave the cloud off — the app works fully without it.

Step 1. Turn on the cloud on the first device

Open “Settings” and turn on the “Cloud” switch — the cloud screen opens. Tap “Create a cloud”. The app shows a QR square, a six-digit number and a 32-character string — that is the key of your cloud. Everyone has their own cloud.

If the device already has codes, the app asks whether to send them all to the cloud or to first choose which ones stay only here. See “Codes that stay out of the cloud” below.

Step 2. Connect the second device

On the second device turn on “Cloud” in the settings, tap “Scan the square” and point the camera at the square on the first one. The second device asks for six digits — at that moment the number is shown on the first device, under the square (it changes every 30 seconds). Enter it, tap “Confirm” — and the codes arrive.

From then on everything is automatic: a new code, an edit and a deletion reach your other devices without a single action. Nothing to remember or write down: the square and the number can be shown again at any time — “Settings” → “Manage my cloud” → “Show the square and the number”.

If there is no camera

On a desktop computer there is a “Cloud key” field instead of a camera: type the 32 characters by hand (they are shown in groups of four) and tap “Join the cloud”. Then the same six digits. This is done once.

Codes that stay out of the cloud

Any code can be kept on one device only — for example, work codes not sent to the home computer. Press and hold a code → “Do not send to the cloud”. Such a code gets a crossed-out cloud icon in the list.

When adding a new code, the “Send to the cloud” question is always asked; the default is to send. If a code was already in the cloud and you take it out, the app asks whether to delete it from your other devices or leave it there.

Codes kept out of the cloud are protected only by a backup file: they do not exist on your other devices.

Still make a backup

The cloud is not storage. While at least one of your devices with the codes is intact, the cloud brings them to a new one. If none is left, the cloud key is gone too, and the codes can be restored only from a backup file (“Backups” → “Create a backup”).

Leaving the cloud

The “Cloud” screen has “Leave the cloud”: the device forgets the key, the codes on it stay intact. It will not rejoin by itself — show it the key from another device again. The “Cloud” switch in settings is different: it only pauses the exchange.

Keep the cloud key safe

Whoever has the key has access to the mailbox. Do not show it to strangers and do not photograph the screen with it: a screenshot lands in the gallery, which other apps can read. There is no need to store the key anywhere — it is on your devices.
