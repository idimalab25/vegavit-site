Comment configurer votre nuage lambit2FA

Le nuage transporte les codes entre vos appareils : ajoutez un code sur le téléphone, il apparaît tout seul sur l’ordinateur. Une configuration, deux minutes.

Ce qu’est le nuage

C’est une boîte aux lettres entre vos appareils, sur notre serveur. Un appareil y dépose un nouveau code, un autre le récupère. La boîte ne sait pas à qui elle appartient et ne peut pas lire ce qu’il y a dedans : les codes sont scellés sur votre appareil avec une clé qui ne va jamais sur le serveur.

Pas de compte, de courriel ni de mot de passe. Vous pouvez laisser le nuage désactivé : l’app fonctionne entièrement sans lui.

Étape 1. Activez le nuage sur le premier appareil

Ouvrez « Réglages » et activez l’interrupteur « Nuage » : l’écran du nuage s’ouvre. Touchez « Créer un nuage ». L’app affiche un carré QR, un nombre à six chiffres et une chaîne de 32 caractères : c’est la clé de votre nuage. Chacun a son propre nuage.

Si l’appareil contient déjà des codes, l’app demande s’il faut tous les envoyer dans le nuage ou d’abord choisir ceux qui restent ici seulement. Voir plus bas « Les codes qui ne vont pas dans le nuage ».

Étape 2. Connectez le second appareil

Sur le second appareil, activez « Nuage » dans les réglages, touchez « Scanner le carré » et visez le carré du premier avec la caméra. Le second appareil demande six chiffres : à ce moment-là le nombre est affiché sur le premier, sous le carré (il change toutes les 30 secondes). Saisissez-le, touchez « Confirmer », et les codes arrivent.

Ensuite tout est automatique : un nouveau code, une modification et une suppression atteignent vos autres appareils sans aucune action. Rien à retenir ni à noter : le carré et le nombre peuvent être réaffichés à tout moment — « Réglages » → « Gérer mon nuage » → « Afficher le carré et le nombre ».

S’il n’y a pas de caméra

Sur un ordinateur de bureau, un champ « Clé du nuage » remplace la caméra : tapez les 32 caractères à la main (ils sont affichés par groupes de quatre) et touchez « Rejoindre le nuage ». Ensuite, les mêmes six chiffres. Cela se fait une fois.

Les codes qui ne vont pas dans le nuage

N’importe quel code peut rester sur un seul appareil — par exemple, ne pas envoyer les codes du travail sur l’ordinateur de la maison. Appui long sur le code → « Ne pas envoyer dans le nuage ». Ce code reçoit dans la liste une icône de nuage barré.

À l’ajout d’un nouveau code, la question « Envoyer dans le nuage » est toujours posée ; par défaut, on envoie. Si un code était déjà dans le nuage et que vous le retirez, l’app demande s’il faut le supprimer de vos autres appareils ou l’y laisser.

Les codes hors du nuage ne sont protégés que par un fichier de sauvegarde : ils n’existent pas sur vos autres appareils.

Faites quand même une sauvegarde

Le nuage n’est pas un stockage. Tant qu’au moins un de vos appareils avec les codes est intact, le nuage les apporte sur un nouveau. S’il n’en reste aucun, la clé du nuage a disparu aussi, et les codes ne se restaurent que depuis un fichier de sauvegarde (« Sauvegardes » → « Créer une sauvegarde »).

Quitter le nuage

L’écran « Nuage » a « Quitter le nuage » : l’appareil oublie la clé, ses codes restent intacts. Il ne rejoindra pas tout seul : montrez-lui de nouveau la clé depuis un autre appareil. L’interrupteur « Nuage » des réglages est autre chose : il met seulement l’échange en pause.

Protégez la clé du nuage

Qui a la clé a accès à la boîte. Ne la montrez pas à des inconnus et ne photographiez pas l’écran qui l’affiche : la capture va dans la galerie, que d’autres apps peuvent lire. Inutile de conserver la clé quelque part : elle est sur vos appareils.
